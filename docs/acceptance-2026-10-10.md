## 定时设计

- 每小时 :07 全日期查询，先查重点日期 20 日；:22/:37/:52 只查 20 日。
- GitHub schedule 使用 UTC，以上分钟间隔在北京时间相同；业务日期和显示都用 Asia/Shanghai。
- 仓库变量 MONITOR_ENABLED 控制正式定时运行。验收结果展示给用户后，已于北京时间 2026-10-10 10:56:39 设置为 true，并通过 GitHub API 回读确认。
- 单轮串行，无并发覆盖；每个结果立即持久化，防止后续日期失败丢失已完成查询。
- 20 日依据最近官网成功记录的起飞时刻停止。首次默认时刻为实际官网读取到的 16:35。不是实时航班起飞动态追踪。
- 所有日期结束后停止查询，22 日第一个跨界调度自动禁用该工作流，已发布历史页继续保留。
- GitHub schedule 可能延迟，不承诺整点执行或严格 15 分钟。
